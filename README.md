# 🎮 퀴즈 게임 (Quiz Game)

파이썬으로 만든 간단한 콘솔(터미널) 퀴즈 게임입니다.
4지선다 문제를 풀고, 점수를 기록하며, 나만의 문제를 추가할 수 있습니다.

## 📌 프로젝트 개요

메뉴에서 번호를 선택해 퀴즈를 풀고, 직접 문제를 추가하며,
최고 점수를 기록할 수 있는 콘솔 기반 퀴즈 게임입니다.
데이터는 JSON 파일에 저장되어 프로그램을 껐다 켜도 유지됩니다.

## 💭 퀴즈 주제 선정 이유

파이썬 기초 문법을 주제로 선택했습니다.
스스로 파이썬을 복습하며 문제를 만들수록 개념이 더 확실히 정리되고,
다른 입문자들도 재미있게 기초를 점검할 수 있다고 생각했기 때문입니다.

## ✨ 기능 목록

- 📝 **퀴즈 풀기**: 4지선다 문제를 풀고 즉시 정답 확인
- ➕ **퀴즈 추가**: 직접 새로운 문제를 만들어 추가
- 📋 **퀴즈 목록**: 등록된 모든 문제 확인
- 🏆 **점수 확인**: 최고 점수(best score) 기록 및 확인
- 💾 **자동 저장**: JSON 파일로 데이터 유지 (껐다 켜도 유지됨)

## 🚀 실행 방법

```bash
python main.py
```

실행하면 메뉴가 나타납니다. 원하는 번호를 입력하세요.

```
===== 퀴즈 게임 =====
1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 점수 확인
5. 종료
```

## 🗂️ 파일 구조

| 파일 | 설명 |
|------|------|
| `main.py` | 프로그램 시작점 (메뉴 실행) |
| `quiz.py` | Quiz 클래스 (문제 1개 담당) |
| `quiz_game.py` | QuizGame 클래스 (게임 전체 관리) |
| `state.json` | 퀴즈 데이터 및 점수 저장 파일 |

## 💾 데이터 파일 설명 (state.json)

- 퀴즈 목록과 최고 점수를 **UTF-8 인코딩**의 JSON 형식으로 저장합니다.
- 프로그램 실행 시 자동으로 불러오고, 변경 시 자동으로 저장됩니다.
- 파일이 **없으면** 기본 퀴즈 데이터로 시작합니다.
- 파일이 **손상되었으면** 안내 메시지를 출력하고 기본 데이터로 복구합니다.
